# nOOb - Tienda de Videojuegos

Tienda online de videojuegos con estética Synthwave/Retrowave.

## Tecnologías utilizadas

- HTML5 semántico
- CSS3 (Flexbox, Grid, Media Queries, animaciones)
- JavaScript (manipulación del DOM, consumo de API)
- Google Fonts (Audiowide, Roboto)
- Font Awesome (iconos)
- Formspree (formulario de contacto)
- RAWG API (novedades de videojuegos)
- GitHub Pages (hosting)

## Estructura del proyecto

noob-tienda/
├── index.html
├── style.css
├── Juegos.js # Base de datos de productos
├── productos.js # Renderizado dinámico de cards
├── carrito.js # Lógica del carrito de compras
├── novedades.js # Consumo de API RAWG
└── README.md

## Funcionalidades

- Renderizado dinámico de productos desde un array
- Carrito de compras con agregar, eliminar y vaciar
- Contador de items en tiempo real
- Panel lateral del carrito con total en ARS
- Sección Novedades con datos reales desde la API de RAWG
- Formulario de contacto funcional con Formspree
- Diseño responsivo para mobile y desktop

## Secciones

- **Inicio** — presentación y trailers de videojuegos
- **Productos** — cards de juegos disponibles
- **Novedades** — juegos populares traídos desde la API de RAWG
- **Reseñas** — opiniones de usuarios
- **Contacto** — formulario funcional
