# nOOb - Tienda de Videojuegos

Tienda online de videojuegos con estética Synthwave/Retrowave.

## Tecnologías utilizadas

- HTML5 semántico
- CSS3 (Flexbox, Grid, Media Queries, animaciones)
- Google Fonts (Audiowide, Roboto)
- Font Awesome (iconos)
- Formspree (formulario de contacto)
- GitHub Pages (hosting)

## Secciones

- **Inicio** — presentación y trailers de videojuegos
- **Productos** — cards de juegos disponibles
- **Reseñas** — opiniones de usuarios
- **Contacto** — formulario funcional
